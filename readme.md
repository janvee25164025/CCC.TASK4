# NIMBUS 3.0 - Project Documentation

## 1. Project Overview

NIMBUS 3.0 is a modern event website for a Cloud Computing Cell technical summit.

## 2. Objective

- Create an attractive and user-friendly event website.
- Display event information clearly.
- Provide speaker and event schedule details.
- Provide an online registration interface.

## 3. Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and layout
- Font Awesome – Icons
- Google Fonts – Outfit font
- Unsplash – Images
- VS Code – Development

## 4. Main Features

- Fixed navigation bar
- Home/Event introduction
- About section
- Event timeline
- Speaker cards
- Event perks
- Registration form
- Smooth scrolling
- Glassmorphism UI

## 6. Working

The website is developed using HTML and CSS. HTML is used to create the structure and content of the website, while CSS is used for styling, layout, colors, fonts, glassmorphism effects, hover effects, and smooth scrolling. Users can navigate through Home, About, Speakers, Perks, and Register sections using the navigation bar. The registration section provides a form to enter user details.

## 7. Future Scope

In the future, the project can be improved by connecting the registration form to a database, adding JavaScript for form validation, adding backend functionality, improving mobile responsiveness, and connecting real social media links. More features like registration confirmation and event reminders can also be added.

## 8. Conclusion

NIMBUS 3.0 is a modern technical event website developed using HTML and CSS. It provides event details, speaker information, event schedule, perks, and a registration interface in an organized and attractive way. The project demonstrates the practical use of HTML and CSS concepts such as Flexbox, forms, navigation, hover effects, and glassmorphism design.
